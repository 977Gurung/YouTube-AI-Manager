# Security

## Reporting a problem
Please report security issues privately through GitHub's **Report a vulnerability** button (Security tab of this
repository) rather than a public issue. Include the version (`./ytm.sh version`) and steps to reproduce.

## Running it safely
- **Keep the dashboard off the public internet.** It listens on `127.0.0.1` by default. `install.sh --lan` opens
  it to your local network only (firewall rule for your subnet). For remote access use an SSH tunnel or a private
  network such as Tailscale, never a router port-forward.
- **API key.** The dashboard and API are protected by `YTM_API_KEY` in `.env` (generated by the installer). Treat it
  like a password; anyone with it can approve, upload, restart or shut down the server.
- **Secrets stay out of git.** `.env`, `secrets/` (Google OAuth client), `data/tokens/` (channel tokens),
  `config/n8n.env` and your `config/channels.yaml` are ignored by `.gitignore`. Run `./scripts/check.sh` before
  pushing; it fails if any of them is tracked or if a key-shaped string appears in the code.
- **Power controls.** `/etc/sudoers.d/ytm-power` lets the service user run exactly three `systemctl` commands
  (reboot, power off, restart the app's two services) and nothing else. Remove it with
  `./scripts/setup-power.sh --remove`.
- **Google OAuth.** The OAuth client (`secrets/client_secret.json`) and channel tokens (`data/tokens/`) grant upload
  access to your channels: never share or commit them. Only sign in with accounts you control.
