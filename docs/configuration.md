# Configuration

Four files, all in the project folder. After editing, run `./ytm.sh restart` (or for channels only,
`./ytm.sh sync-channels` / dashboard → Channels → **Reload channels.yaml**).

| File | Holds | In git? |
|---|---|---|
| `.env` | Keys and secrets (created from `.env.example` by the installer) | No |
| `config/settings.yaml` | Machine-wide settings with comments for every key | Yes (defaults) |
| `config/channels.yaml` | Your channels (created from `config/channels.example.yaml`) | No |
| `config/n8n.env` | n8n service settings (generated by the installer) | No |

## .env
| Variable | Required | Purpose |
|---|---|---|
| `YTM_API_KEY` | Yes (generated) | Protects the API and dashboard; n8n sends it as `X-API-Key`. Show it: `./ytm.sh key` |
| `YOUTUBE_API_KEY` | Recommended | YouTube Data API key for research and analytics |
| `GOOGLE_CLIENT_SECRETS` | Yes for uploads | Path of the OAuth Desktop client JSON (default `./secrets/client_secret.json`) |
| `PEXELS_API_KEY`, `PIXABAY_API_KEY` | No | Stock footage |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | No | Paid voice provider |

## settings.yaml
Every key is commented in the file; the main sections:

| Section | What it controls |
|---|---|
| `app` | `host` (127.0.0.1 = local only, 0.0.0.0 = network), `port` 8765, `timezone` for publishing slots, `data_dir` |
| `worker` | `isolate`: job kinds that run in their own process so memory is returned after each video |
| `power` | `enabled`: Restart / Shut down buttons on the System tab |
| `monitor` | System tab sampling: `interval_s`, `history_s` |
| `llm` | Ollama URL and model (`qwen2.5:7b-instruct`), `keep_alive` |
| `gpu` | Whisper model and precision, video encoder (`h264_nvenc`, falls back to `libx264`) |
| `voice` | Default provider, Chatterbox emotion settings and fallback, Piper model folder |
| `video` | Frame rate, music folder and volume, Short / long sizes, caption styles |
| `media` | Visual source order (`broll`, `stock`, `ai`), b-roll folder and match score, stock providers |
| `ai_images` | SDXL model, Lightning LoRA, steps, sizes, style |
| `ai_video` | LTX-Video animation: scope, clip limits, time budget, size, frames |
| `research` | `trends_geo` (one or more countries, e.g. `"AE, US"`), ideas per run, pending-idea limit, dedupe |
| `youtube` | Quota and reserve, default category, made-for-kids, AI disclosure, caption upload, OAuth port |
| `approval` | Default approval gates |

## channels.yaml
One block per channel; see `config/channels.example.yaml` for two complete examples.

| Field | Example | Meaning |
|---|---|---|
| `slug`, `name` | `tech-simplified`, `Tech Simplified` | ID used in commands, display name (required) |
| `niche`, `audience`, `tone`, `language` | | Steer research and script writing |
| `formats`, `mix` | `[short, long]`, `{short: 3, long: 1}` | What to make and in what ratio |
| `voice` | `{provider: chatterbox, exaggeration: 0.6}` | Voice per channel (see below) |
| `brand` | `{primary: "#FFD400", text: "#FFFFFF"}` | Thumbnail and caption colours |
| `visuals`, `visual_style`, `broll_dir` | `[broll, ai]` | Visual sources, AI image style, own clip folder |
| `schedule` | `short: ["11:00", "19:00"]`, `long: ["Sat 16:00"]` | Publishing slots in `app.timezone` |
| `max_uploads_per_day` | `3` | Upload cap |
| `youtube` | `{category_id: "28"}` | Category and per-channel YouTube overrides |
| `approval_gates` | `[idea, script, final]` | Which steps wait for you; `[final]` = only watch the finished video |
| `research` | `trends_geo`, `keywords`, `subreddits`, `rss`, `competitors` | Research sources |
| `description_footer` | | Text appended to every description |
| `animate`, `motion_style`, `caption_style` | `false`, `"slow pan"`, `karaoke` | Per-channel animation and caption overrides |

## Visuals
Each script section takes its picture from the first source that has one (`media.order`, or `visuals:` per channel):

| Source | How to use it | Notes |
|---|---|---|
| Own clips (`broll`) | Put MP4s in `assets/broll/`; file and folder names are the search words, e.g. `assets/broll/city/traffic-night-rain.mp4` | Best quality and fully yours |
| Stock (`stock`) | `PIXABAY_API_KEY` / `PEXELS_API_KEY` in `.env` | Optional; Pexels has paused new keys |
| AI images (`ai`) | On by default; `./ytm.sh fetch-models` downloads SDXL once | About 10–15 s per image on an RTX 2070 (estimate); then animated (below) or shown with a slow zoom/pan |

When a video uses AI images, the upload sets YouTube's *altered or synthetic content* flag
(`youtube.disclose_ai_images`) and the description notes it.

## Voice
| Provider | Quality | Notes |
|---|---|---|
| `chatterbox` | Natural, with emotion | Local GPU, free. Install with `./ytm.sh setup-voice`. Falls back to `voice.chatterbox.fallback` if it fails |
| `piper` | Clear but flat | Local CPU, fast. Check each voice's licence |
| `edge` | Natural | Free online Microsoft voices; needs internet |
| `elevenlabs` | Best | Paid; key in `.env` |

Chatterbox settings per channel:
```yaml
    voice:
      provider: chatterbox
      exaggeration: 0.6      # emotion strength: 0.3 calm, 0.5 neutral, 0.7-0.9 lively/dramatic
      emotion: auto          # more energy on the hook, on "!" / "?" and the closing line; fixed = same everywhere
      cfg_weight: 0.4        # 0.3 = slower, more deliberate; 0.6 = tighter
      temperature: 0.8       # lower = steadier
      speed: 1.0
      # reference: ./assets/voice-ref.wav   # 10-20 s clean recording: the narration takes on that voice and accent
```
Only use a reference recording of your own voice or one you have permission to use. Hear the result with
`./ytm.sh voice-sample <slug>` (writes `data/voice-sample-<slug>.wav`).

## AI animation (LTX-Video)
| Setting (`ai_video`) | Default | Meaning |
|---|---|---|
| `scope.short` / `scope.long` | `all` / `key` | `all` = every AI still; `key` = hook + first scene of each chapter; `none` = off |
| `max_clips` | 16 / 12 | Upper limit per video |
| `max_minutes` | 150 / 240 | Time budget per video; scenes not reached stay as stills |
| `frames`, `fps` | 97, 24 | 4-second clips, slowed up to 1.35x then played forward-backward to fill longer scenes |

Expect a few minutes per clip on an RTX 2070 (a Short takes roughly 1–2 hours). Animation never fails a video:
if the model is missing, runs out of memory or time, those scenes stay as stills and the reason is in the video's
History. Turn it off per channel with `animate: false`.

## Captions
`video.captions.short_style` / `long_style`: `pop` (default) | `karaoke` | `plain` | `none`; per channel
`caption_style:`. `pop` shows words one by one in time with the voice; the spoken word pops in the brand colour and
key words (numbers, acronyms, power words, title words) get a larger, tilted pop in `keyword_color`.
